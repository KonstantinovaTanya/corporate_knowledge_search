# Тестовые сценарии проверки прав доступа

## 1. Проверка сотрудника (employee)

| №   | Сценарий                                                      | Ожидаемый результат                             |
| --- | ------------------------------------------------------------- | ----------------------------------------------- |
| 1   | Сотрудник просматривает доступные документы                   | Документы доступны в соответствии с его правами |
| 2   | Сотрудник добавляет новый документ                            | Документ успешно добавлен                       |
| 3   | Сотрудник изменяет собственный документ                       | Изменение разрешено                             |
| 4   | Сотрудник изменяет документ другого сотрудника                | Доступ запрещён                                 |
| 5   | Сотрудник удаляет собственный документ                        | Удаление разрешено                              |
| 6   | Сотрудник удаляет чужой документ                              | Доступ запрещён                                 |
| 7   | Сотрудник просматривает историю запросов другого пользователя | Доступ запрещён                                 |
| 8   | Сотрудник просматривает собственную историю запросов          | Просмотр разрешён                               |

## 2. Проверка руководителя (department_head)

| №   | Сценарий                                                                       | Ожидаемый результат       |
| --- | ------------------------------------------------------------------------------ | ------------------------- |
| 9   | Руководитель подразделения просматривает доступные документы                   | Доступ разрешён           |
| 10  | Руководитель подразделения добавляет новый документ                            | Документ успешно добавлен |
| 11  | Руководитель подразделения изменяет документ своего подразделения              | Изменение разрешено       |
| 12  | Руководитель подразделения изменяет документ другого подразделения             | Доступ запрещён           |
| 13  | Руководитель подразделения удаляет документ своего подразделения               | Удаление разрешено        |
| 14  | Руководитель подразделения удаляет документ другого подразделения              | Доступ запрещён           |
| 15  | Руководитель подразделения просматривает историю запросов своего подразделения | Доступ разрешён           |
| 16  | Руководитель подразделения просматривает историю другого подразделения         | Доступ запрещён           |

## 3. Проверка администратора (admin)

| №   | Сценарий                                                   | Ожидаемый результат       |
| --- | ---------------------------------------------------------- | ------------------------- |
| 17  | Администратор просматривает документы разных подразделений | Доступ разрешён           |
| 18  | Администратор добавляет документы в любое подразделение    | Документ успешно добавлен |
| 19  | Администратор изменяет любой документ                      | Изменение разрешено       |
| 20  | Администратор удаляет любой документ                       | Удаление разрешено        |
| 21  | Администратор управляет пользователями и ролями            | Доступ разрешён           |
| 22  | Администратор просматривает общую историю запросов         | Доступ разрешён           |

## 4. Проверка безопасности поиска

| № | Сценарий | Ожидаемый результат |
| --- | ------------------------------------------------------------------------ | ------------------------------------------------------- | |
| 23 | В доступном и закрытом документах есть похожие сведения | Ответ формируется только на основе доступного документа |
| 24 | Пользователь задаёт вопрос, ответа на который нет в доступных документах | Система сообщает, что информация не найдена |
| 25 | Сотрудник ищет информацию в документе другого подразделения с ограниченным доступом | Документ не попадает в результаты поиска, сведения не используются в ответе |
| 26 | Руководитель ищет информацию в документе другого подразделения с ограниченным доступом | Документ не попадает в результаты поиска, сведения не используются в ответе |
| 27 | Администратор ищет информацию в документах разных подразделений | Поиск выполняется по всем документам, доступ разрешён |
