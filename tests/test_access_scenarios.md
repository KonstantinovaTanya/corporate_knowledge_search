# Тестовые сценарии проверки прав доступа

## 1. Проверка сотрудника (employee)

| №   | Сценарий                                                      | Ожидаемый результат                                               |
| --- | ------------------------------------------------------------- | ----------------------------------------------------------------- |
| 1   | Сотрудник просматривает доступные документы                   | Документы доступны в соответствии с его правами                   |
| 2   | Сотрудник добавляет новый документ                            | Документ успешно добавлен                                         |
| 3   | Сотрудник изменяет собственный документ                       | Изменение разрешено                                               |
| 4   | Сотрудник изменяет документ другого сотрудника                | Доступ запрещён                                                   |
| 5   | Сотрудник удаляет собственный документ                        | Удаление разрешено                                                |
| 6   | Сотрудник удаляет чужой документ                              | Доступ запрещён                                                   |
| 7   | Сотрудник ищет информацию в закрытом документе                | Сведения из закрытого документа не попадают в результаты и ответы |
| 8   | Сотрудник просматривает историю запросов другого пользователя | Доступ запрещён                                                   |
| 9   | Сотрудник просматривает собственную историю запросов          | Просмотр разрешён                                                 |

## 2. Проверка руководителя (manager)

| №   | Сценарий                                                         | Ожидаемый результат |
| --- | ---------------------------------------------------------------- | ------------------- |
| 10  | Руководитель просматривает документы своего подразделения        | Доступ разрешён     |
| 11  | Руководитель изменяет документ своего подразделения              | Изменение разрешено |
| 12  | Руководитель удаляет документ своего подразделения               | Удаление разрешено  |
| 13  | Руководитель изменяет документ другого подразделения             | Доступ запрещён     |
| 14  | Руководитель удаляет документ другого подразделения              | Доступ запрещён     |
| 15  | Руководитель просматривает историю запросов своего подразделения | Доступ разрешён     |
| 16  | Руководитель просматривает историю другого подразделения         | Доступ запрещён     |

## 3. Проверка администратора (admin)

| №   | Сценарий                                                   | Ожидаемый результат |
| --- | ---------------------------------------------------------- | ------------------- |
| 17  | Администратор просматривает документы разных подразделений | Доступ разрешён     |
| 18  | Администратор изменяет любой документ                      | Изменение разрешено |
| 19  | Администратор удаляет любой документ                       | Удаление разрешено  |
| 20  | Администратор управляет пользователями и ролями            | Доступ разрешён     |
| 21  | Администратор просматривает общую историю запросов         | Доступ разрешён     |

## 4. Проверка безопасности поиска

| №   | Сценарий                                                                 | Ожидаемый результат                                     |
| --- | ------------------------------------------------------------------------ | ------------------------------------------------------- |
| 22  | Пользователь ищет сведения, содержащиеся только в недоступном документе  | Информация не раскрывается                              |
| 23  | В доступном и закрытом документах есть похожие сведения                  | Ответ формируется только на основе доступного документа |
| 24  | Пользователь задаёт вопрос, ответа на который нет в доступных документах | Система сообщает, что информация не найдена             |
