# Матрица прав доступа

## 1. Роли пользователей

В системе предусмотрено три роли:

- **Сотрудник (employee)** — обычный пользователь системы.
- **Руководитель подразделения (department_head)** — руководитель, управляющий документами своего подразделения.
- **Администратор (admin)** — пользователь с полным доступом к системе.

## 2. Права доступа

| Действие                                  | Сотрудник -- | Руководитель         | Администратор |
| ----------------------------------------- | ------------ | -------------------- | ------------- |
| Просмотр доступных документов             | Да           | Да                   | Все документы |
| Поиск информации                          | Да           | Да                   | Да            |
| Добавление документов                     | Да           | Да                   | Да            |
| Изменение собственных документов          | Да           | Да                   | Да            |
| Удаление собственных документов           | Да           | Да                   | Да            |
| Изменение документов своего подразделения | Нет          | Да                   | Да            |
| Удаление документов своего подразделения  | Нет          | Да                   | Да            |
| Управление пользователями                 | Нет          | Нет                  | Да            |
| Управление ролями и правами               | Нет          | Нет                  | Да            |
| Просмотр истории запросов                 | Собственная  | Своего подразделения | Вся           |

## 3. Правила доступа

1. **Просмотр документов:**
   - Сотрудник может читать все документы своего подразделения независимо от авторства, если уровень доступа документа это разрешает.
   - Руководитель может читать документы своего подразделения и общедоступные документы.
   - Администратор имеет доступ ко всем документам.

2. **Изменение документов:**
   - Сотрудник может изменять только документы, которые добавил самостоятельно.
   - Руководитель может изменять документы своего подразделения.
   - Администратор может изменять любые документы.

3. **Удаление документов:**
   - Сотрудник может удалять только документы, которые добавил самостоятельно.
   - Руководитель может удалять документы своего подразделения.
   - Администратор может удалять любые документы.

4. **Поиск информации:**
   - Перед поиском система проверяет права доступа пользователя.
   - В результаты поиска и сформированные ответы не должны попадать сведения из документов, недоступных пользователю.

5. **История запросов:**
   - Сотрудник может просматривать собственную историю запросов.
   - Руководитель может просматривать историю запросов своего подразделения.
   - Администратор может просматривать всю историю запросов.
