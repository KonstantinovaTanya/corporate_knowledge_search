# Матрица прав доступа

## 1. Роли пользователей

В системе предусмотрено три роли:

- **Сотрудник (employee)** — обычный пользователь системы.
- **Руководитель подразделения (manager)** — руководитель, управляющий документами своего подразделения.
- **Администратор (admin)** — пользователь с полным доступом к системе.

## 2. Права доступа

| Действие                                  | Сотрудник -- | Руководитель         | Администратор |
| ----------------------------------------- | ------------ | -------------------- | ------------- |
| Просмотр доступных документов             | Да           | Да                   | Все документы |
| Поиск информации                          | Да           | Да                   | Да            |
| Добавление документов                     | Да           | Да                   | Да            |
| Изменение собственных документов          | Да           | Да                   | Да            |
| Удаление собственных документов           | Да           | Да                   | Да            |
| Изменение документов своего подразделения | Нет          | Да                   | Да            |
| Удаление документов своего подразделения  | Нет          | Да                   | Да            |
| Управление пользователями                 | Нет          | Нет                  | Да            |
| Управление ролями и правами               | Нет          | Нет                  | Да            |
| Просмотр истории запросов                 | Собственная  | Своего подразделения | Вся           |

## 3. Правила доступа

1. Сотрудник может изменять и удалять только документы, которые добавил самостоятельно.
2. Руководитель может изменять и удалять документы только своего подразделения.
3. Администратор имеет полный доступ к содержимому документов и управлению системой.
4. Перед поиском система проверяет права пользователя.
5. В результаты поиска и ответы не должны попадать сведения из документов, недоступных пользователю.
6. История запросов доступна сотруднику в пределах его прав: собственная история, история подразделения для руководителя, вся история для администратора.
