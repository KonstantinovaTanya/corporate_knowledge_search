# Пользовательский сценарий Corporate Knowledge Search

## Основной сценарий

```mermaid
flowchart TD
    A([Начало]) --> B[Авторизация пользователя]
    B --> C[Определение роли и подразделения]
    C --> D[Ввод вопроса]
    D --> E[Обработка запроса]
    E --> F[Поиск документов]
    F --> G{Документы найдены?}

    G -- Нет --> H[Сообщение: информация не найдена]
    G -- Да --> I[Проверка прав доступа]

    I --> J{Доступ разрешён?}
    J -- Нет --> K[Отказ в доступе без раскрытия содержимого]
    J -- Да --> L[Формирование ответа по документам]

    L --> M[Добавление ссылок на источники]
    M --> N[Отображение ответа пользователю]

    H --> O([Завершение])
    K --> O
    N --> O
```

## Результат сценария

Пользователь получает ответ на свой вопрос на основании доступных ему корпоративных документов. Ответ сопровождается ссылками на источники. Если информации нет или доступ запрещён, система сообщает об этом без раскрытия закрытых сведений.
