1. Общая информация

Название проекта: Corporate Knowledge Search
Корпоративная система поиска знаний и формирования ответов по внутренней документации

Участник проекта: Константинова Татьяна

2. Назначение программы

Corporate Knowledge Search — программная система, предназначенная для загрузки, хранения и обработки внутренних PDF- и DOCX-документов организации, поиска информации по их содержимому и формирования ответов на вопросы пользователей с обязательным указанием источников.

Основная цель проекта — предоставить сотрудникам единый инструмент для быстрого поиска необходимой информации и формирования ответов на вопросы на основании корпоративной документации.

Система должна обеспечивать обязательное указание источников информации и проверку прав доступа пользователей перед поиском и формированием ответов.

В качестве исходных материалов используются внутренние инструкции, регламенты, приказы, положения и учебные руководства в форматах PDF и DOCX.

3. Предполагаемые технологии

Python 3.14 - Основной язык программирования

FastAPI - Разработка серверной части и API

Uvicorn - Запуск ASGI-сервера

PostgreSQL - Хранение пользователей, ролей, документов и истории запросов

Elasticsearch - Полнотекстовый поиск и индексация документов

PyMuPDF - Извлечение текста из PDF

python-docx - Извлечение текста из DOCX

python-dotenv - Загрузка конфигурации из переменных окружения

5. Установка и запуск

Клонирование проекта:
git clone <ссылка-на-репозиторий>
cd corporate_knowledge_search

Если проект уже находится на компьютере, достаточно открыть его папку в VS Code.

Создание виртуального окружения
py -3.14 -m venv .venv

Активация виртуального окружения
.\.venv\Scripts\Activate.ps1

Установка зависимостей
python -m pip install -r requirements.txt

Запуск приложения
python -m uvicorn app.main:app --reload

После запуска приложение будет доступно по адресу:
http://127.0.0.1:8000

Документация API (Swagger UI):
http://127.0.0.1:8000/docs
