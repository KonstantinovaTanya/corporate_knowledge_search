# Corporate Knowledge Search

**Корпоративная система поиска знаний и формирования ответов по внутренней документации.**

## 1. Общая информация

- **Название проекта:** Corporate Knowledge Search
- **Участник проекта:** Константинова Татьяна

## 2. Назначение проекта

Corporate Knowledge Search — программная система, предназначенная для загрузки, хранения и обработки внутренних документов организации в форматах PDF и DOCX.

Система предоставляет пользователям возможность:

- Искать информацию по содержимому корпоративных документов.
- Формировать ответы на вопросы на основании найденной информации.
- Получать ответы с обязательным указанием источников.
- Работать с документами с учётом ролевой модели и прав доступа.

**Основная цель проекта** — предоставить сотрудникам единый инструмент для быстрого поиска необходимой информации и получения ответов на вопросы на основании корпоративной документации.

Система должна проверять права доступа пользователя перед поиском и формированием ответа, чтобы исключить использование информации из документов, недоступных конкретному пользователю.

В качестве исходных материалов используются внутренние инструкции, регламенты, приказы, положения и учебные руководства.

## 5. Установка и запуск

### 5.1. Клонирование проекта

Клонировать репозиторий с GitHub:

```bash
git clone https://github.com/KonstantinovaTanya/corporate_knowledge_search.git
```

Перейти в папку проекта:

```bash
cd corporate_knowledge_search
```

### 5.2. Создание виртуального окружения

Создать виртуальное окружение Python:

```bash
python -m venv venv
```

### 5.3. Активация виртуального окружения

Windows (PowerShell):

```powershell
.\venv\Scripts\Activate.ps1
```

### 5.4. Установка зависимостей

Установить необходимые библиотеки:

```bash
pip install -r requirements.txt
```

### 5.5. Настройка конфигурации

В корне проекта создать файл `.env` и указать настройки подключения к SQL Server и Elasticsearch.

Копирование шаблона в файл `.env`:
Copy-Item .env.example .env

```env
APP_NAME=Corporate Knowledge Search
APP_DESCRIPTION=Система поиска знаний и ответов по внутренней документации
APP_VERSION=0.1.0
APP_ENV=development

# SQL Server
SQL_SERVER=ИМЯ_ВАШЕГО_КОМПЬЮТЕРА
SQL_DATABASE=CorporateKnowledgeSearch
SQL_DRIVER=ODBC Driver 18 for SQL Server
SQL_TRUSTED_CONNECTION=yes
SQL_TRUST_SERVER_CERTIFICATE=yes

# Elasticsearch
ELASTICSEARCH_URL=https://localhost:9200
ELASTICSEARCH_USER=elastic
ELASTICSEARCH_PASSWORD=ВАШ_ПАРОЛЬ
```

В параметре `SQL_SERVER` указать имя SQL Server, используемого на компьютере. В параметре `ELASTICSEARCH_PASSWORD` указать пароль пользователя Elasticsearch.

### 5.6. Запуск SQL Server

Установить и запустить Microsoft SQL Server. Убедиться, что сервер доступен и настроено подключение с использованием Windows Authentication.

Создание базы данных, таблиц и заполнение справочников выполняется автоматически при подготовке проекта.

### 5.7. Запуск Elasticsearch

Установить и запустить Elasticsearch. Убедиться, что сервис доступен по адресу, указанному в `ELASTICSEARCH_URL`, и настроены учетные данные для подключения.

### 5.8. Подготовка базы данных и тестовых документов

Выполнить команду:

```bash
python setup_project.py
```

Скрипт автоматически:

- создаёт базу данных и необходимые таблицы;
- заполняет справочники ролей и уровней доступа;
- импортирует тестовые документы из PDF и DOCX в SQL Server;
- создаёт поисковый индекс Elasticsearch;
- индексирует документы для дальнейшего поиска.

### 5.9. Запуск приложения

Запустить приложение командой:

```bash
uvicorn app.main:app --reload
```

После запуска API доступно по адресу:

http://127.0.0.1:8000

Документация API Swagger:

http://127.0.0.1:8000/docs
