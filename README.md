# Corporate Knowledge Search

**Корпоративная система поиска знаний и формирования ответов по внутренней документации.**

## 1. Общая информация

- **Название проекта:** Corporate Knowledge Search
- **Участник проекта:** Константинова Татьяна

## 2. Назначение проекта

Corporate Knowledge Search — программная система, предназначенная для загрузки, хранения и обработки внутренних документов организации в форматах PDF и DOCX.

Система предоставляет пользователям возможность:

- Искать информацию по содержимому корпоративных документов.
- Формировать ответы на вопросы на основании найденной информации.
- Получать ответы с обязательным указанием источников.
- Работать с документами с учётом ролевой модели и прав доступа.

**Основная цель проекта** — предоставить сотрудникам единый инструмент для быстрого поиска необходимой информации и получения ответов на вопросы на основании корпоративной документации.

Система должна проверять права доступа пользователя перед поиском и формированием ответа, чтобы исключить использование информации из документов, недоступных конкретному пользователю.

В качестве исходных материалов используются внутренние инструкции, регламенты, приказы, положения и учебные руководства.

## 3. Предполагаемые технологии

| Технология    | Назначение                                                   |
| ------------- | ------------------------------------------------------------ |
| Python 3.14   | Основной язык программирования                               |
| FastAPI       | Разработка серверной части и API                             |
| Uvicorn       | Запуск ASGI-сервера                                          |
| PostgreSQL    | Хранение пользователей, ролей, документов и истории запросов |
| Elasticsearch | Полнотекстовый поиск и индексация документов                 |
| PyMuPDF       | Извлечение текста из PDF                                     |
| python-docx   | Извлечение текста из DOCX                                    |
| python-dotenv | Загрузка конфигурации из переменных окружения                |

На текущем этапе настроено базовое приложение на FastAPI. Остальные компоненты будут подключаться по мере реализации функциональности.

## 5. Установка и запуск

### 5.1. Клонирование репозитория

```powershell
git clone https://github.com/KonstantinovaTanya/corporate_knowledge_search.git
cd corporate_knowledge_search
```

### 5.2. Создание виртуального окружения

```powershell
py -3.14 -m venv .venv
```

### 5.3. Активация виртуального окружения

```powershell
.\.venv\Scripts\Activate.ps1
```

### 5.4. Установка зависимостей

```powershell
python -m pip install -r requirements.txt
```

### 5.5. Запуск приложения

```powershell
python -m uvicorn app.main:app --reload
```

После запуска приложение будет доступно по адресу:

- **Главная страница:** http://127.0.0.1:8000
- **Документация API (Swagger UI):** http://127.0.0.1:8000/docs

## 6. Тестовые материалы

Для разработки и проверки качества системы подготовлена тестовая база, включающая:

- 100 документов в форматах PDF и DOCX.
- Документы четырёх основных подразделений и административного отдела.
- Различные уровни доступа к документам.
- 50 контрольных вопросов для проверки поиска и формирования ответов.

Тестовый набор включает вопросы по отдельным документам, вопросы, требующие использования нескольких источников, сценарии частичного доступа и вопросы, на которые отсутствует ответ в документации.
